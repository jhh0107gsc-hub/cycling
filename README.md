# Cycling Training App

## 프로젝트 목표

공개 사이클링 훈련 데이터와 개인 라이딩 데이터를 분석하여
훈련 상태를 시각화하고, 오늘 수행할 훈련을 추천하는 앱을 만든다.

## 현재까지 진행 내용

1. GoldenCheetah 라이딩 기록을 정리하고, 날짜별·주별 훈련 흐름을 확인했습니다.
2. 추천일 이전 기록만 사용하도록 최근 7일·28일 TSS, TSS 비율, 운동 시간, 라이드 횟수, 전날 기록 맥락을 feature로 만들었습니다.
3. 최근 부하 수준과 전날 기록 상태를 조합한 규칙 기반 추천 결과를 만들었습니다.
4. 추천일 이후 7일의 TSS를 사후적으로 확인해, 규칙별 결과 흐름을 비교했습니다.
5. 날짜를 입력하면 저장된 규칙 기반 추천 결과의 훈련 맥락과 안내 문장을 조회할 수 있게 했습니다.

## 규칙 기반 추천의 역할

현재 규칙은 기계학습 이전의 기준선이며, 훈련 기록에서 어떤 feature가 추천 맥락을 설명하는지 파악하기 위한 단계입니다. 모든 추천 입력값은 추천일 이전 기록으로 계산해 미래 정보가 섞이지 않도록 했습니다.

추천 결과는 과거 훈련량 흐름을 바탕으로 한 검토용 안내입니다. 기록이 없는 날을 휴식일로 단정하지 않으며, 실제 피로·회복 상태나 개인별 훈련 처방을 확정하지 않습니다.

## 다음 단계

규칙 기반으로 확인한 feature를 입력값으로 사용하고, 추천일 이후 7일의 TSS를 정답값으로 하는 기계학습용 데이터를 준비합니다. 학습과 평가는 시간 순서를 지켜 분리하고, 규칙 기반 결과를 비교 기준으로 활용합니다.
